# JINX Enterprise Agent System & Web Dashboard

Интеллектуальная система автономного агента **JINX** с интерактивной веб-панелью управления для визуализации когнитивного цикла, логов, состояния планов и архитектурных решений в реальном времени.

---

## Архитектура проекта

При интеграции в ваш рабочий проект, структура каталогов должна выглядеть следующим образом:

```text
Ваш_Проект/
├── .agent/                    # Папка JINX-агента
│   ├── JINX.yaml              # Актуальное состояние агента (автоматически обновляется)
│   ├── jinx.py                # Точка входа для запуска агента в CLI
│   ├── jinx_run_state.yaml    # Активное состояние выполнения и история диалога/команд
│   ├── src/
│   │   └── jinx/              # Ядро логики и модули JINX
│   │
│   └── webagent/              # Веб-интерфейс визуализации (данный сайт)
│       ├── package.json       # Зависимости и конфигурационные скрипты сайта
│       ├── server.ts          # Express + Vite backend сервер
│       ├── tsconfig.json
│       ├── vite.config.ts
│       ├── index.html
│       ├── src/               # React (TypeScript) клиентское приложение
│       └── ...
```

## 1. Установка и запуск Python-агента (JINX)

### Требования
* Python 3.10 или выше
* Установленный менеджер пакетов `pip`

### Инициализация и запуск
Перейдите в корень вашего проекта (`Ваш_Проект/`) и запустите агента, передав ему задачу. При первом запуске скрипт автоматически скачает необходимые зависимости (`pydantic` и `pyyaml`):

```bash
python .agent/jinx.py "Создай систему авторизации пользователей"
```

Агент развернет когнитивный цикл, начнет выполнять итерации, создавать/модифицировать файлы через инструменты и сохранять текущий прогресс в файлы `.agent/JINX.yaml` и `.agent/jinx_run_state.yaml`.

## 2. Установка и запуск Веб-панели управления (webagent)

Веб-приложение построено на стеке **React + Express + Vite** и автоматически отслеживает работу агента JINX, выводя интерактивные графики, шаги плана, консоль терминала и измененные файлы в реальном времени.

### Шаг 1: Переход в директорию веб-агента
Из корня вашего основного проекта перейдите в папку сайта:
```bash
cd .agent/webagent
```

### Шаг 2: Установка Node.js зависимостей
Убедитесь, что у вас установлена Node.js (рекомендуется v18+). Установите зависимости проекта:
```bash
npm install
```

### Шаг 3: Запуск в режиме разработки (Vite HMR + Express)
Запустите сервер разработки. Он автоматически поднимет Express backend и Vite на порту **3301**:
```bash
npm run dev
```
Откройте браузер по адресу: **`http://localhost:3301`**

### Шаг 4: Сборка и запуск в Production
Для сборки оптимизированного клиентского бандла и компиляции сервера:
```bash
# Сборка проекта
npm run build

# Запуск Production-сервера
npm run start
```

## Функциональные возможности панели

1. **Cognitive Loop (Когнитивный Цикл)**:
   Показывает текущую фазу работы агента (Perceive, Plan, Execute, Verify), прошедшее время, PID запущенного процесса и системные ресурсы.
2. **Multi-Step Plan (План действий)**:
   Отображает интерактивные шаги выполнения, результаты тестов и пройденные требования для каждого раунда оптимизации.
3. **Workspace Insights (Факты, Долг и Задачи)**:
   * **Выявленные Факты (Scope Facts)** — выписанные агентом ограничения и факты из окружения.
   * **Открытые Задачи (Open Requirements)** — оставшиеся нерешенные вопросы.
   * **Технический Долг (Design Debt)** — принятые временные компромиссы или обходные пути.
4. **Terminal Console & RPC Log**:
   Полная трассировка всех вызовов инструментов (чтение/запись файлов, запуск bash скриптов) и вывод терминала в реальном времени.
5. **Файловый проводник и просмотр Diff**:
   Возможность просматривать исходный код созданных агентом файлов и изучать детальную подсветку изменений (`diff`).
